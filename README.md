LIFE MAP

「お店の今が、行く前にわかる。」

LIFE MAPは、店舗の混雑状況や商品在庫状況を来店前に確認できるプラットフォームです。

主な機能（予定）

- 店舗検索
- 地図・一覧表示
- 混雑状況の確認
- 商品在庫状況の確認
- 店舗向け管理画面
- 運営者向け管理画面
- POSシステム連携

技術構成

- Next.js
- Supabase
- Netlify
- Google Places API
- Gmail API

セキュリティ方針

開発段階から本番環境と同等のセキュリティ基準を採用します。

- HTTPSの使用
- Supabase RLSによるアクセス制御
- APIキー・秘密情報のサーバー側管理
- ロールベースアクセス制御

開発状況

現在、初期開発準備中です。
